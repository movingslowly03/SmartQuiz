# SmartQuiz

SmartQuiz is a web-based AI-powered quiz platform developed using PHP and MySQL. The system allows lecturers to upload learning materials and automatically generate quizzes from the uploaded content using the Gemini API.

The platform supports three main user roles: **Admin**, **Lecturer**, and **Student**. Each role has access to different features based on their responsibilities within the system.

## Features

### Admin
- Manage subjects
- View registered users
- View available quizzes
- View quiz results and performance data
- Monitor overall system activity

### Lecturer
- Upload learning materials
- Support for PDF, DOCX, and TXT files
- Generate quizzes automatically using AI
- Choose the number of questions
- Select quiz difficulty
- View generated quizzes
- View student quiz results
- Monitor student performance

- Attempt quizzes online
